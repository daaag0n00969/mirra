# Mirra

**Интерактивное HUD-зеркало для Android** — отзеркаливает любое приложение на лобовое стекло, **не блокируя кнопки плеера**.

> Версия **0.1.2** — превью для установки с GitHub. В Google Play, RuStore и F-Droid **пока не публикуется**.

[English README](README.md) · [Релизы / APK](https://github.com/daaag0n00969/mirra/releases)

## Зачем это нужно

В обычных HUD-зеркалах полноэкранный оверлей перехватывает все касания. Пока картинка отзеркалена, нельзя нажать Play, паузу или кнопку на карте — только закрыть программу и начать заново.

Mirra оставляет перевёрнутую картинку и даёт управлять приложением:

- **Нажатия насквозь** — оверлей только рисует, плеер снизу живой.
- **Плавающая кнопка** поверх всех окон: нажатие скрывает/показывает зеркало, удержание — меню, перетаскивание к краю.
- **Зеркальные нажатия** (опционально) — жмёте туда, где кнопку видно после переворота.

Это самостоятельный MIT-проект, не форк Middor.

## Требования

Android **14 QPR2+**. В системном окне захвата выбирайте **одно приложение**, не весь экран.

## Установка

1. Скачайте `Mirra-0.1.2.apk` со [страницы релизов](https://github.com/daaag0n00969/mirra/releases).
2. Разрешите установку из файлов.
3. Выдайте «поверх других окон».
4. «Запустить зеркало» → одно приложение → откройте плеер.
