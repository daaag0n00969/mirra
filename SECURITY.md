# Security

Mirra captures the screen of **one app you pick** and draws it in an overlay on the same device. Nothing is uploaded.

- Overlay and Accessibility are used only to display the HUD and, if enabled, to remap taps.
- The Accessibility service does not read window content (`canRetrieveWindowContent` is off) and does not type.
- Report vulnerabilities privately via GitHub Security Advisories on this repository.
