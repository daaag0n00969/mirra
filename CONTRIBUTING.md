# Contributing

Mirra is at **0.1.x**. Small, reviewable changes are welcome.

1. Open an issue before large features.
2. Keep the overlay pass-through path working — that is the point of the app.
3. Do not add trackers, ads, or network calls.
4. Match existing Kotlin / Compose style.
5. Test on Android 14+ with a real player (YouTube, local video, Maps).

```bash
./gradlew :app:assembleDebug
```
